# ByteBill — Android App

GST billing, inventory & invoicing for small business.
**A unit of Byte Bump — Next Brain Mechatronics Pvt Ltd**

Same trusted ByteBill you know from Windows — now on your phone. Standalone
(no PC needed): your shop's data stays on the device.

## Features

- **Billing** — customer details, product search, serial/IMEI dropdown,
  item / overall / festive / coupon discounts, live GST totals
- **GST invoice PDF** — A4 or thermal (58/80 mm), shareable from the phone
- **Inventory** — products, brands, stock, low-stock alerts, serial/batch/IMEI ledger
- **Reports** — bills list, sales & GST summary, stock report, CSV export
- **Coupons** — percentage coupons with cap + validity
- **Settings** — business profile, logo/stamp/signature, invoice numbering, paper size

## Install

1. Download **`ByteBill-1.0.apk`** from the
   [Releases page](https://github.com/bytbump/ByteBill-Android/releases/latest)
2. Copy it to your Android phone and open the file
3. If asked, allow **Install unknown apps** for your file manager / browser
   (Android shows this prompt for every app installed outside the Play Store)
4. Tap **Install** → open **ByteBill**

Requires Android 7.0 or newer. The APK is release-signed with the official
ByteBill certificate. If upgrading from an older test build, uninstall the
old app first, then install this one.
